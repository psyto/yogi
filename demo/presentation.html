What Went Wrong

Four production bugs found live. Each one taught us something.

Emergency Close Loop
Drawdown close_all only closed directional positions.
DN positions ignored → infinite loop every 30s.
Fix: extracted pure decision function + regression test
Min Order Size
0.0999 SOL orphan < Drift's 0.1 minimum.
Every restart failed on the same transaction.
Fix: check minOrderSize, skip dust
False Drawdown Trigger
Opening DN drops equity temporarily (spot settlement lag).
Emergency check saw 12% "drawdown" → closed everything.
Fix: reset peak equity after opening positions
Funding Churn
POPCAT 84% APY → flipped negative in hours.
Open/close churn cost ~$70 in trading fees.
Fix: 24h minimum hold period
